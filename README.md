# SeeNag-Website

Seenag is a multi-page e-commerce website, a clothing brand that sells comfortable, playful everyday t-shirts.

## Pages
- **Home:** featured tees, brand introduction, customer feedback, and FAQs
- **Shop:** browse the tee collection
- **Product pages:** Don't Be Late Tee, Everyday Comfort Tee, and Do Good Work Tee
- **About** and **Contact**
- **Checkout**

## Features
- Responsive layout that works on desktop
- Accessibility-focused code following WCAG guidelines

## Project Structure
- `css/`: stylesheets
- `js/`: scripts
- `images/`: logos and product photos
- `*.html`: site pages

## How to Run
Download or clone the repository and open `index.html` in a browser, or use a local server such as VS Code's Live Server extension.
